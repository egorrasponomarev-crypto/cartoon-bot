# Бот «Мини-курс по мультикам»

Бесплатный мини-курс из 5 шагов, который прогревает человека и продаёт полный курс.

## Что где лежит

| Файл | Зачем |
|---|---|
| `texts.py` | **Все тексты и кнопки.** Правишь только его. |
| `.env` | **Настройки:** токен, твой ID, канал, цены, таймер, интервалы. |
| `bot.py` | Запуск бота |
| `funnel.py` | Логика воронки: шаги, скидка, оффер, доступ в канал |
| `scheduler.py` | Напоминания |
| `db.py` | База данных (файл `bot.db` появится сам) |
| `handlers/` | Реакции на кнопки и команды |
| остальное | Служебные файлы, трогать не нужно |

**Как открыть `texts.py` и `.env` для правки:** правый клик по файлу → «Открыть с помощью» → «Блокнот». Двойной клик по `texts.py` запускает его, а не открывает. Word и WordPad не подходят: они портят файл.

## 1. Создаём бота и получаем токен

1. Открой в Telegram **@BotFather** → нажми «Запустить» (или напиши `/start`).
2. Отправь `/newbot`.
3. Введи название бота (любое, его видят люди), например: `Мультики в нейросетях`.
4. Введи username бота. Он должен заканчиваться на `bot`, например: `multiki_ai_bot`.
5. BotFather пришлёт **токен** — длинную строку вида `1234567890:AAHk...`. Это пароль от бота: никому его не показывай.

По желанию там же: `/setuserpic` — аватарка, `/setdescription` — текст, который человек видит до нажатия «Запустить».

## 2. Узнаём свой Telegram ID

Напиши `/start` боту **@userinfobot** — он ответит числом `Id: 123456789`. Это твой ID.
(Позже можно проверить и в своём боте командой `/myid`.)

## 3. Настраиваем файл .env

1. В папке `cartoon_bot` скопируй файл `.env.example` и назови копию **`.env`** (с точкой в начале, без `.txt` на конце).
   - Если Windows прячет расширения: в Проводнике «Вид» → поставь галочку «Расширения имён файлов».
2. Открой `.env` Блокнотом и заполни:
   - `BOT_TOKEN=` — токен из шага 1;
   - `ADMIN_ID=` — твой ID из шага 2;
   - `CHANNEL_ID=` — пока оставь пустым, заполним в шаге 5.
3. Сохрани файл.

## 4. Запускаем бота на компьютере (для проверки)

Python у тебя уже установлен. Если будешь ставить на другом компьютере: скачай с python.org и при установке поставь галочку **«Add python.exe to PATH»**.

1. Открой папку `cartoon_bot` в Проводнике.
2. Кликни в адресную строку сверху, напиши `powershell` и нажми Enter — откроется синее окно в этой папке.
3. Один раз установи библиотеки (скопируй и вставь по очереди, после каждой строки — Enter):
   ```
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   ```
4. Открой своего бота в Telegram (ссылку прислал BotFather) и нажми «Запустить». Бот пока молчит — это нормально.
5. Запусти бота:
   ```
   .venv\Scripts\python.exe bot.py
   ```
   Если всё хорошо, появится строка `Бот @... запущен`, и бот пришлёт тебе в Telegram «✅ Бот запущен».
6. Остановить бота: в окне PowerShell нажми `Ctrl + C` и подожди пару секунд.

**Бот работает, только пока открыто это окно и включён компьютер.** Чтобы он работал круглосуточно — шаг 8.

**Если бот не запускается с ошибками `TelegramNetworkError` / `timeout`**, значит, из России не открывается сервер Telegram. Варианты:
1. Включи VPN в режиме «VPN / TUN / весь трафик». Режим «системный прокси» бот не видит.
2. Или впиши в `.env` локальный прокси своего VPN-приложения: `PROXY=socks5://127.0.0.1:ПОРТ`. Порт указан в настройках приложения, в строке SOCKS или «локальный порт».

Перед отправкой бота на сервер строку `PROXY=` нужно очистить (см. шаг 8.1). На сервере за границей прокси не нужен.

## 5. Создаём закрытый канал и добавляем туда бота

1. В Telegram: карандаш / «Новое сообщение» → **«Создать канал»** → название → тип **«Частный»**.
2. Опубликуй в канале уроки (или хотя бы один пост).
3. Добавь бота админом: открой канал → название канала вверху → «Изменить» (карандаш) → **«Администраторы»** → «Добавить администратора» → найди своего бота по username → **оставь включёнными все права** (главное — «Добавление подписчиков» / «Пригласительные ссылки») → «Готово».
4. Узнай ID канала: **перешли любой пост из канала своему боту** (бот должен быть запущен). Он ответит: `ID этого канала: -100...`.
5. Впиши это число в `.env` в строку `CHANNEL_ID=`, сохрани и перезапусти бота (`Ctrl + C`, затем снова `.venv\Scripts\python.exe bot.py`).

## 6. Фото и видео к приветствию и шагам (по желанию)

**Сейчас подключено:**
- в приветствии — `Шаг 0.png`;
- в шаге 1 — кнопка «📥 Скачать мастер-промпт»: бот присылает файл `Мастер_промт_от_Анастасии.md` под именем «Мастер-промпт от Анастасии.txt»;
- в шаге 2 — `Шаг 1.png` (крупно над текстом);
- в шаге 3 — `видео шаг 3.mp4` (текст шага — подпись к видео).

**Проще всего — файлом из папки бота:**
1. Положи файл в папку `cartoon_bot`, например `Шаг 3.mp4`. Размер: фото — до 10 МБ, видео и файлы — до 50 МБ.
   Если бот уже на сервере, загрузи файл и туда. В PowerShell в папке `cartoon_bot`:
   ```
   scp "Шаг 3.mp4" root@213.155.13.213:/root/kyrs/
   ```
   Кавычки нужны из-за пробела в имени.
2. В `texts.py` впиши имя файла **точно как у файла**: на сервере «шаг 3.mp4» и «Шаг 3.mp4» — разные файлы.
   - Для приветствия — в `GREETING_MEDIA`.
   - Для шага — в `STEP_MEDIA`, в квадратные скобки нужного шага:
   ```python
   STEP_MEDIA = {
       ...
       3: [{"type": "video", "file": "Шаг 3.mp4"}],
       ...
   ```
   Тип: `"photo"` — фото, `"video"` — видео, `"animation"` — GIF, `"document"` — файл.
3. Перезапусти бота. Как придёт шаг (и приветствие):
   - одно фото или видео и текст до 1024 символов — одним сообщением, текст станет подписью;
   - одно фото и текст длиннее — тоже одним сообщением, картинка крупно над текстом (см. ниже);
   - в остальных случаях медиа приходит отдельным сообщением перед текстом.

Бот загружает файл в Telegram один раз, а дальше отправляет его мгновенно.
Если файла с таким именем нет или он слишком большой, бот при запуске напишет об этом.
Если картинка всё-таки не отправится, текст шага всё равно придёт, а тебе придёт предупреждение.

**Картинка над длинным текстом.** Подпись к фото в Telegram — не длиннее 1024 символов. Чтобы шаг с длинным текстом всё равно был одним сообщением, бот кладёт картинку в папку веб-сервера и показывает её крупно над текстом. Для этого в `.env` заполнены две строки (на нашем сервере уже настроено):
```
MEDIA_WEB_DIR=/var/www/html/kyrs-media
MEDIA_BASE_URL=http://213.155.13.213/kyrs-media
```
Картинки больше 1 МБ бот сам пересохраняет в JPG поменьше: такие картинки Telegram берёт только до 5 МБ. Если строки пустые, картинка придёт отдельным сообщением перед текстом.
Если веб-сервер на сервере не работает, Telegram просто не покажет такую картинку, а бот об этом не узнает и предупреждения не пришлёт. Поэтому после обновления открой шаг 2 в боте и проверь, что картинка над текстом на месте.

**Файл по кнопке под шагом** (как мастер-промпт на шаге 1). Положи файл в папку бота и впиши его в `STEP_DOWNLOADS` в `texts.py`: номер шага, имя файла, надпись на кнопке и подпись к файлу. `"filename"` — имя, под которым файл получит ученик (можно не указывать). Размер — до 50 МБ.

**Другой способ — file_id:** отправь боту со своего аккаунта фото или видео. Он ответит строчкой вида `{"type": "video", "file_id": "BAAC..."}`, её можно вставить вместо строчки с `"file"`.

## 7. Проверяем всю воронку в тестовом режиме

В тестовом режиме каждый «час» из настроек длится минуту. Всё, что обычно занимает сутки, происходит за минуты.

**Включаем:** в `.env` поставь `TEST_MODE=true` и перезапусти бота.
Для ускорения можно поставить `TEST_HOUR_SECONDS=10`: тогда 1 «час» = 10 секунд. Но тогда и скидка длится всего 4 минуты, поэтому сам оффер со скидкой проверяй при `60`.

Что и когда придёт при `TEST_HOUR_SECONDS=60`:

| Событие | Обычно | В тесте |
|---|---|---|
| Скидка действует | 24 часа с первого входа | 24 минуты |
| «Скоро конец скидки» | за 3 часа до конца | на 21-й минуте |
| «Скидка закончилась» | через 24 часа | на 24-й минуте |
| «Как там шаг N?» | через 24 ч после открытия шага | через 24 мин |
| «Ты остановился на шаге N» | через 72 ч | через 72 мин |
| Напоминание после оффера | через 24 ч | через 24 мин |
| «Давно не виделись» | через 7 дней тишины | через 168 мин (для теста поставь `INACTIVITY_HOURS=10` → 10 мин) |

Особые случаи:
- Если «Как там шаг N?» совпадает по времени со «Скидка закончилась», он придёт на 2 часа позже, чтобы не было двух сообщений подряд. Так обычно бывает с шагом 1: в тесте — на 26-й минуте.
- Ночью (23:00–09:00 по Москве) бот не пишет и переносит сообщения на 10:00. Исключение — «Скоро конец скидки». Если к 10:00 скидка уже закончится, это сообщение придёт накануне около 22:30, и в нём будет точное оставшееся время. В тестовом режиме ночное правило отключено.
- Админу (тебе) напоминания приходят только в тестовом режиме. В обычном режиме бот тебя ими не беспокоит.

**Чек-лист проверки** (ты одновременно админ и «ученик»).

Со своего аккаунта админа некоторые вещи выглядят иначе, чем у учеников:
- на обычный текст без кнопок бот отвечает подсказкой, а не пересылает его тебе;
- на фото отвечает его file_id.

Вопрос через кнопку «💬 Задать вопрос автору» в оффере работает как у всех.
Проверить «просто написал боту» можно со второго аккаунта (например, попроси друга).

Скидка в тесте длится всего 24 минуты. Проходи шаги 1–5 быстро, иначе на шаге 5 уже будет кнопка «🎓 Узнать про полный курс» и полная цена — так и должно быть после конца скидки.

1. `/reset` — стирает твой прогресс, как будто ты новый человек.
2. Открой ссылку `https://t.me/ИМЯ_БОТА?start=test1` (подставь username бота) → «Запустить». Появится приветствие с кнопкой «🚀 Начать шаг 1». Нижнего меню у бота нет: все кнопки — под сообщениями.
3. «🚀 Начать шаг 1» → кнопки «👉 Шаг 2…», «👉 Шаг 3…» и т.д. до шага 5.
   - Каждый новый шаг **заменяет** предыдущий: старые сообщения исчезают, чат не засоряется.
   - Под каждым шагом есть «👈 Назад»; с шага 1 она возвращает к приветствию.
   - С шага 3 есть кнопка «Что внутри полного курса». Из оффера «👈 Назад» возвращает на тот шаг, откуда его открыли.
   - `/start` всегда начинает с приветствия и кнопки «🚀 Начать шаг 1».
4. На любом шаге: «🆘 Нужна помощь» → откроется чат с админом. Ссылку можно поменять в `.env`, строка `HELP_URL`.
5. Открой оффер (с шага 3 — кнопка «🎓 Что внутри полного курса») → «💬 Задать вопрос автору» → напиши вопрос. Тебе как админу придёт карточка ученика и сам вопрос. **Ответь** на него (свайп влево / «Ответить») — ответ придёт «ученику», то есть тебе же, от имени бота.
6. На шаге 5 → «🎁 Забрать курс со скидкой» → оффер с зачёркнутой ценой и таймером. Проверь «Программа подробнее», «Частые вопросы», «Задать вопрос автору».
7. Подожди до конца скидки: на 21-й минуте придёт «Через … цена вернётся…», на 24-й — «Скидка закончилась». Нажми под ним «🎓 Полный курс»: должна быть только полная цена.
8. Напоминания о шагах: `/reset`, `/start`, сразу открой шаг 1 и ничего не нажимай. Что придёт:
   - на 21-й и 24-й минутах — сообщения о скидке;
   - на 26-й — «как там шаг 1?»;
   - на 72-й — «Ты остановился на шаге 1».
9. «Давно не виделись»: поставь `INACTIVITY_HOURS=10`, перезапусти, `/reset`, `/start` и 10 минут ничего не нажимай.
    Ученики в обычном режиме получат другой вариант текста — `INACTIVE_7_DAYS_NO_DISCOUNT`, потому что через 7 дней скидки уже нет. Увидеть его в тесте можно с `INACTIVITY_HOURS=30`.
10. **Оплата звёздами.** Звёзды списываются настоящие, даже в тестовом режиме. Для проверки временно поставь `PRICE_FULL_STARS=1` и `PRICE_DISCOUNT_STARS=1`, купи немного звёзд и оплати. Должна прийти одноразовая ссылка в канал, а тебе — «💰 Новая оплата». Потом верни звёзды себе: `/refund ТВОЙ_ID`.
    (Если ты владелец канала, бот не сможет удалить тебя из него и напишет об этом — это нормально.)
11. `/stats` — статистика: источник `test1`, шаги, оплаты.
12. `/broadcast` → «Не купившим» → пришли текст → «Отправить».
13. **Перед запуском для людей:** верни `TEST_MODE=false`, цены и `INACTIVITY_HOURS=168`, перезапусти бота и сделай `/reset`.

**Проверь цену в звёздах до запуска.** Telegram не публикует, сколько звёзд максимум можно запросить в одном счёте. Раньше лимит был 2500 ⭐. Поставь настоящие цены, нажми «💳 Оплатить» и убедись, что окно оплаты открылось. Если Telegram не примет сумму, бот сразу напишет тебе об этом.

## 8. Сервер, чтобы бот работал 24/7

> **Бот уже развёрнут на сервере `213.155.13.213`:**
> - папка: `/root/kyrs`;
> - настройки: `/root/kyrs/.env`;
> - сервис автозапуска: `kyrs-bot`.
>
> Во всех командах ниже вместо `/opt/cartoon_bot` подставляй `/root/kyrs`, а вместо `cartoon-bot` — `kyrs-bot`. Например, обновить тексты:
> ```
> scp texts.py root@213.155.13.213:/root/kyrs/
> ssh root@213.155.13.213 systemctl restart kyrs-bot
> ```
> Посмотреть, что делает бот: `ssh root@213.155.13.213 journalctl -u kyrs-bot -n 50`.
> Новую версию бота (код, картинки, видео) на этот сервер отправляй по разделу 8.6.
> Остальная часть раздела 8 — общая инструкция на случай нового сервера.

**Важно: сервер должен быть за границей** (Нидерланды, Германия, Финляндия, Польша). С российских серверов с весны 2026 года Telegram API почти не открывается, и бот «молчит».

Боту хватит самого маленького тарифа: 1 ядро, 1 ГБ памяти, система **Ubuntu 24.04**. Примеры с оплатой российской картой (цены на сентябрь 2026, примерные):
- VDSina, Амстердам — от ~150 ₽/мес;
- FirstByte, Амстердам — от ~430 ₽/мес;
- Timeweb Cloud, Нидерланды — от ~830 ₽/мес (самая понятная панель для новичка).

После покупки провайдер пришлёт **IP-адрес** сервера и **пароль** от пользователя `root`.

### 8.1. Упаковываем и отправляем бота на сервер

⚠️ **Перед упаковкой:**
1. Останови бота на компьютере (`Ctrl + C`): две копии одновременно работать не могут.
2. Открой `.env` и проверь:
   - `TEST_MODE=false`;
   - строка `PROXY=` пустая;
   - настоящие цены `PRICE_FULL_STARS` / `PRICE_DISCOUNT_STARS`;
   - `INACTIVITY_HOURS=168`.

   Сохрани файл: он уедет на сервер как есть.

Открой PowerShell в папке **над** `cartoon_bot`, то есть в папке «сайт настюхи»:
- если окно PowerShell сейчас открыто в `cartoon_bot`, набери `cd ..` и нажми Enter;
- или открой папку «сайт настюхи» в Проводнике и напиши `powershell` в адресной строке.

Выполни (вместо `1.2.3.4` — IP твоего сервера):
```
tar -czf bot.tar.gz --exclude=.venv --exclude=__pycache__ --exclude=bot.db* --exclude=backup.db cartoon_bot
scp bot.tar.gz root@1.2.3.4:/opt/
```
Команда `tar` должна отработать молча. Если она написала ошибку, значит, ты не в той папке.
В архиве `bot.tar.gz` лежит `.env` с токеном бота. После отправки на сервер удали архив с компьютера. На GitHub он не попадёт: архивы и базы данных добавлены в `.gitignore`.
На вопрос `Are you sure you want to continue connecting` напиши `yes`, потом введи пароль. Пароль при вводе не отображается — это нормально.

### 8.2. Устанавливаем на сервере

Подключись к серверу:
```
ssh root@1.2.3.4
```
Дальше вставляй команды по одной:
```
apt update && apt install -y python3 python3-venv
cd /opt && tar --no-same-permissions -xzf bot.tar.gz && chmod 600 cartoon_bot/.env && cd cartoon_bot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python bot.py
```
Если появилось «Бот … запущен», останови его (`Ctrl + C`) и сделай автозапуск.

### 8.3. Автозапуск (бот сам поднимется после перезагрузки и сбоев)

Скопируй и вставь целиком:
```
cat > /etc/systemd/system/cartoon-bot.service << 'EOF'
[Unit]
Description=Cartoon course bot
After=network-online.target
Wants=network-online.target

[Service]
WorkingDirectory=/opt/cartoon_bot
ExecStart=/opt/cartoon_bot/.venv/bin/python bot.py
Restart=always
RestartSec=5
Environment=PYTHONUNBUFFERED=1

[Install]
WantedBy=multi-user.target
EOF
systemctl daemon-reload
systemctl enable --now cartoon-bot
```

Полезные команды на сервере:
- `systemctl status cartoon-bot` — работает ли бот;
- `journalctl -u cartoon-bot -f` — смотреть, что происходит (выход — `Ctrl + C`);
- `systemctl restart cartoon-bot` — перезапустить (после правки текстов или настроек);
- `systemctl stop cartoon-bot` — остановить.

### 8.4. Как поменять тексты или настройки, когда бот уже на сервере

Поправь `texts.py` (или `.env`) на компьютере. Потом открой PowerShell в папке `cartoon_bot`.

1. Проверь, что в `texts.py` нет ошибок:
   ```
   .venv\Scripts\python.exe -m py_compile texts.py
   ```
   Если команда ничего не написала, всё в порядке. Если написала `SyntaxError` с номером строки, исправь эту строку.
2. Отправь файлы и перезапусти бота:
   ```
   scp texts.py root@1.2.3.4:/opt/cartoon_bot/
   scp .env root@1.2.3.4:/opt/cartoon_bot/
   ssh root@1.2.3.4 systemctl restart cartoon-bot
   ```
   Вторую строку выполняй, только если менял `.env`. Перед этим проверь в нём: `TEST_MODE=false` и пустой `PROXY=`.
   На сервере в `.env` есть ещё две строки — `MEDIA_WEB_DIR` и `MEDIA_BASE_URL` (раздел 6). Если их нет в твоём `.env`, допиши перед отправкой, иначе картинка к шагу 2 снова будет приходить отдельным сообщением.
3. Через несколько секунд придёт «✅ Бот запущен». Если не пришло, посмотри ошибку:
   ```
   ssh root@1.2.3.4 journalctl -u cartoon-bot -n 30
   ```

### 8.5. Резервная копия базы (ученики, оплаты, статистика)

В PowerShell в папке «сайт настюхи» (не внутри `cartoon_bot`):
```
ssh root@1.2.3.4 "cd /opt/cartoon_bot && .venv/bin/python -c 'import sqlite3,sys; sqlite3.connect(sys.argv[1]).backup(sqlite3.connect(sys.argv[2]))' bot.db /root/backup.db"
scp root@1.2.3.4:/root/backup.db .
```
Рядом появится файл `backup.db`: это копия базы.

Восстановить базу из копии:
```
ssh root@1.2.3.4 systemctl stop cartoon-bot
scp backup.db root@1.2.3.4:/opt/cartoon_bot/bot.db
ssh root@1.2.3.4 "rm -f /opt/cartoon_bot/bot.db-wal /opt/cartoon_bot/bot.db-shm && systemctl start cartoon-bot"
```

**Вариант без сервера и командной строки: хостинг Amvera** (регион Варшава, тариф Starter, ~290 ₽/мес).
1. Создай проект Python (pip).
2. Загрузи через сайт все файлы из `cartoon_bot`, кроме папок `.venv` и `__pycache__` и файлов `bot.db*`.
3. В конфигурации укажи:
   - версию Python 3.12;
   - файл зависимостей `requirements.txt`;
   - файл запуска `bot.py`;
   - постоянное хранилище `/data`.
4. В `.env` (или в переменных проекта) укажи `DB_PATH=/data/bot.db`, `TEST_MODE=false` и пустой `PROXY=`.

Точные названия полей сверь с документацией Amvera.

### 8.6. Как отправить на сервер новую версию бота

Нужно, когда поменялся не только `texts.py`, а и сам код бота, картинки, видео или файлы для скачивания. Файл `.env` и база учеников на сервере при этом не меняются.

1. Открой PowerShell в папке `cartoon_bot` и проверь, что в коде нет ошибок:
   ```
   .venv\Scripts\python.exe -m compileall -q -l . handlers
   ```
   Если команда ничего не написала, всё в порядке.
2. Отправь код, тексты и все файлы, которые указаны в `texts.py` (картинки, видео, мастер-промпт). Скопируй и вставь целиком:
   ```
   scp (Get-ChildItem *.py).Name requirements.txt "Мастер_промт_от_Анастасии.md" "Шаг 0.png" "Шаг 1.png" "видео шаг 3.mp4" root@213.155.13.213:/root/kyrs/
   scp -r handlers root@213.155.13.213:/root/kyrs/
   ```
   Если добавишь новую картинку или видео, допиши её имя в кавычках в первую строку.
3. Доустанови библиотеки (если в `requirements.txt` появилось новое) и перезапусти бота:
   ```
   ssh root@213.155.13.213 "cd /root/kyrs && .venv/bin/pip install -r requirements.txt && systemctl restart kyrs-bot"
   ```
4. Через несколько секунд придёт «✅ Бот запущен». Если пришло «⚠️ В texts.py есть ошибки или незаполненные места», исправь то, что там перечислено. Если ничего не пришло, посмотри ошибку:
   ```
   ssh root@213.155.13.213 journalctl -u kyrs-bot -n 30
   ```
5. Пройди в боте шаги 1–3 со своего аккаунта: картинка над текстом на шаге 2, видео на шаге 3, кнопка «📥 Скачать мастер-промпт» на шаге 1.

## Что заполнить в texts.py

Все места в [квадратных скобках] нужно заменить своими данными (вместе со скобками). Исключение — скобки `[ ]` в `GREETING_MEDIA` и `STEP_MEDIA` и скобки `[ … ]` вокруг шага из нескольких сообщений в `STEP_TEXTS`: это не места для текста, их не удаляй.

| Где в texts.py | Что вписать |
|---|---|
| `GREETING` | ✅ заполнено |
| `STEP_TEXTS` шаг 1 | ✅ заполнено (файл мастер-промпта — в `STEP_DOWNLOADS`) |
| `STEP_TEXTS` шаг 2 | ✅ заполнено |
| `STEP_TEXTS` шаг 3 | ✅ заполнено |
| `STEP_TEXTS` шаг 4 | ✅ заполнено (настоящий отзыв ученика можно добавить, когда появится) |
| `STEP_TEXTS` шаг 5 | [сервис озвучки и базовая инструкция]; [базовая инструкция по монтажу]; [как выложить…]; [диапазон цен]; [твой пример]; [Если есть: «Моя ученица [имя]…»] — или удали строку |
| `OFFER` | [Название курса]; [уроки, домашки, чат, обратная связь…] |
| `PROGRAM` | [Бонусы, если есть…] — или удали строку |
| `FAQ` | 7 ответов: [ответ] ×6 и [честный ответ: примерные расходы…] |
| `OFFER_REMIND_24` и `OFFER_REMIND_24_NOT_FINISHED` | [короткий отзыв или результат ученика] |
| `INVOICE_TITLE` | [Название курса] (не длиннее 25 символов) |
| `LINK_PAID_THANKS` | [время] (нужно только для режима link) |
| `PAYMENT_SUCCESS` | [первого урока / закреплённого сообщения] |
| `PAYSUPPORT` | [@username], [время] |
| `TERMS` | [ссылка на оферту или условия…], [@username] |
| `GREETING_MEDIA`, `STEP_MEDIA`, `STEP_DOWNLOADS` | по желанию: фото или видео к приветствию и шагам, файл по кнопке под шагом (см. раздел 6) |

## Команды админа

| Команда | Что делает |
|---|---|
| `/stats` | Статистика: пользователи, источники, шаги, оффер, оплаты, конверсии |
| `/broadcast` | Рассылка всем / купившим / не купившим (текст, фото, видео). Остановить уже идущую — кнопка «⏹ Остановить рассылку» |
| `/fileid` | Прислать фото или видео и получить file_id (или просто пришли файл боту) |
| `/reset` | Сбросить свой прогресс и пройти воронку заново |
| `/refund ID` | Вернуть оплату звёздами и убрать ученика из канала |
| `/grant ID` | Выдать доступ вручную или новую ссылку в канал, если ученик потерял старую |
| `/admin` | Список команд |

- **Ответить ученику:** ответь (reply) на его сообщение, которое переслал бот.
- **ID ученика** есть в каждой карточке, которую присылает бот.

## Если что-то не работает

- **Бот молчит.** Проверь, что окно с ботом открыто (или на сервере `systemctl status cartoon-bot`). Посмотри ошибки в окне или в `journalctl -u cartoon-bot -f`.
- **Ошибка `Conflict: terminated by other getUpdates request`.** Бот запущен в двух местах. Останови лишнюю копию.
- **Не приходят результаты и вопросы учеников.** Нажми `/start` в своём боте со своего аккаунта и проверь `ADMIN_ID` в `.env`.
- **После оплаты не создалась ссылка в канал.** Бот не админ канала или неверный `CHANNEL_ID`. Бот пришлёт тебе ошибку. Исправь и выдай доступ: `/grant ID_ученика`.
- **Текст в `texts.py` изменён, а бот пишет старый.** Перезапусти бота.
- **Ошибка после правки `texts.py`.** Скорее всего, случайно удалены кавычки или запятая. Сравни с резервной копией.
- **Бот при запуске пишет «В texts.py есть ошибки или незаполненные места».** В тексте осталось место в [квадратных скобках], которое нужно заменить своим текстом, или есть символ `<` или `&`, незакрытый тег, текст длиннее 4096 символов. Бот покажет, в каком именно тексте.
- **У ученика осталось нижнее меню со старой версии бота.** Оно исчезнет при его следующем нажатии или сообщении: бот один раз пришлёт «Обновила бота: нижнего меню больше нет…» (текст `MENU_REMOVED` в `texts.py`).
